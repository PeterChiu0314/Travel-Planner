## 修正與尚未驗證的門檻

1. 不改 13 個原檔／歷史 ledger；新增版本大於現有 head 的 terminal Forward，安裝封包不得在修正前 commit 任何中間態。
2. 以最終 live 定義做局部 errcode literal 轉換，保留全部其他 pg_proc 屬性、guards、RLS、財務及 request receipt。不得改 engine 的錯誤語意。
3. 離線 before/after fingerprint 是候選；特別是 B-7 動態 legacy Save gate 仍未封存。需要另授權隔離 full-chain compilation、fault rollback、fresh chronological chain／Staging out-of-order chain、idempotency 及 native engine conflict regression，不能把 5 個 lexer 測試當作 SQL/HTTP 通過。
4. 群組 controller 的未套用 PT409 patch 同樣是部署 gate；測 Metadata admission/commit、Payment/Source/Lifecycle/Undo 的共用 controller、Receipt retain-request hook 與未知 ACK，不能只測已修正的舊 whole-form service。
5. 後續 CI 建議將任何新增 custom RAISE 40001／unreviewed function rewrite 視為 fail-closed；原已套用歷史 source 的既有 literals 需用精確 immutable hash 例外，不做粗略全 repository grep 零容忍。
